## What it does

Orient you among the existing skills and the product UX extension. It explains the route without starting work merely because a capability was described.

## When to reach for it

You invoke this with `/ask-matt`; the agent does not start it automatically. Reach for it when choosing between a focused interview, Wayfinder, prototyping, synthesis, or implementation.

## Common questions

**Do I need a new coordinator for UX and Product Design?**

No. The current interview and map use a shared UX guide; prototype routes visual work to the external plugin; synthesis and execution assess readiness.

## It's working if

The recommended route matches the uncertainty and scale, and technical work without experience impact stays lightweight.

## Where it fits

This is the router over the full workflow. Start with [grill-with-docs](https://github.com/rtellez91/mattpocock-skills-fork/blob/product-ux/docs/engineering/grill-with-docs.md) for a focused interview, or [Wayfinder](https://github.com/rtellez91/mattpocock-skills-fork/blob/product-ux/docs/engineering/wayfinder.md) when related decisions need a persistent map.
