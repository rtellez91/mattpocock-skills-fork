# Canonical installation for this fork

Use the maintained `main` branch and the preview-first local installer documented in [INSTALL.md](../INSTALL.md). That document is the single maintained installation and migration procedure for this fork.

The package is named `mattpocock-skills-fork`; individual skill names stay unchanged. Do not recommend the original marketplace as the source of these adaptations, or install another source with the same active names alongside this one. Product Design remains a separately installed plugin.

Other installation routes have not been validated for this fork. Preserve upstream examples in Git history, not as competing instructions in the current README.
