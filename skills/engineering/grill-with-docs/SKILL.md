Call the Skill tool twice, for "grilling" and "domain-modeling".

For product-experience work, also call the Skill tool with "ux-discovery" in discovery mode. Use its criteria within the same interview: the agent chooses and explains useful UX methods, brings findings back to the open questions, and keeps domain terminology and decisions in their existing canonical homes. Internal changes with no experience impact need only a brief applicability check.

Before ending, distinguish decisions resolved for the agreed interview scope from explicitly deferred design questions. State what the latter block. A completed requirements discussion does not automatically mean every interface is ready to implement.
